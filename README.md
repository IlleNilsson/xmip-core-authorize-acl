# xmip-core-authorize-acl

Access-control list: entries of subject, action, target pattern and allow or deny, first match wins and a contradicting pair is a denial. A technology of [xmip-core-authorize](https://github.com/IlleNilsson/xmip-core-authorize).

## Toolchain

`rust-toolchain.toml` pins the toolchain for the whole estate. Do not change it
here.

## Verification

The included workflow is manual-only and calls the versioned shared workflow at
`IlleNilsson/.github@v1`.
